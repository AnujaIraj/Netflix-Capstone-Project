Netflix Recommendation System using Collaborative Filtering and SVD to suggest movies based on user preferences and rating patterns.

# Netflix Recommendation System

## Project Overview
This project builds a movie recommendation system using the Netflix rating dataset. The system predicts user preferences and recommends movies by analyzing user–movie rating patterns using Collaborative Filtering and Singular Value Decomposition (SVD).

## Dataset
Netflix Prize Dataset released by Netflix containing large-scale movie ratings from users.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-Learn
- Surprise Library
- Jupyter Notebook / Google Colab

## Steps
1. Data Loading and Preprocessing
2. Exploratory Data Analysis (EDA)
3. Creating User–Movie Interaction Matrix
4. Applying Collaborative Filtering
5. Model Building using SVD
6. Model Evaluation

## Results
The recommendation system successfully predicts user ratings and generates personalized movie recommendations using collaborative filtering techniques.
